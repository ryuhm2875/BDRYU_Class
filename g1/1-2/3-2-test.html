형태소
1형태소더 나누면 본래의 뜻을 잃어버리는 가장 작은 단위.
2③‘바다’를 ‘바’와 ‘다’로 나누면 뜻이 사라진다. 형태소 하나가 곧 단어.
3가, 를, -었-, -다영수 / 가 / 딸기 / 를 / 먹- / -었- / -다. ‘영수, 딸기, 먹-’은 실질 형태소.
4④‘먹-’, ‘보-’는 혼자 못 쓰이는 의존 형태소지만 동작의 뜻이 있는 실질 형태소.
5③어간 ‘보-’, 과거를 나타내는 ‘-았-’, 문장을 끝내는 ‘-다’로 나뉜다.
6⑤‘수고’는 혼자 쓰이고 실질적인 뜻도 있다. ‘보-’는 실질 형태소지만 의존 형태소.
7(1) 하늘 / 이 / 맑- / -다
(2) 하늘 (3) 이, 맑-, -다		조사 ‘이’는 의존 형태소지만 붙임표를 쓰지 않는다.
어근과 접사
8①접사는 어근에 붙어야만 단어가 된다.
9②‘햇-’은 ‘그해에 새로 난’의 뜻을 더하는 접사. 나머지는 모두 어근.
10한겨울: 겨울 / 한-
나무꾼: 나무 / -꾼		‘한-’은 ‘한창인’, ‘-꾼’은 ‘그 일을 하는 사람’의 뜻을 더한다.
11①② 풋-, ③ 맨-, ④ 시-, ⑤ 한-의 뜻.
12⑤‘감나무’는 어근 ‘감’과 ‘나무’로만 이루어졌다. 맨-, 풋-, -개, -보는 접사.
단일어 · 합성어 · 파생어
13㉠ 단일어 ㉡ 합성어
㉢ 파생어		합성어와 파생어를 묶어 복합어라고 한다.
14②‘마을’은 하나의 어근. 손발·밤낮은 합성어, 맨발·웃음은 파생어.
15④‘맨발’만 접사 ‘맨-’이 붙은 파생어. 나머지는 어근끼리 만난 합성어.
16①날- + 고기, 멋 + -쟁이. ② 합성어끼리, ③ 단일어끼리, ④·⑤ 합성어와 파생어가 섞임.
17④‘오르-’와 ‘내리다’는 둘 다 어근이므로 합성어.
18집안, 오르내리다웃음(-음), 재롱둥이(-둥이), 맨발(맨-)은 파생어.
19(예시)‘손발’은 어근 ‘손’과 어근 ‘발’이 결합했고, ‘맨발’은 접사 ‘맨-’과 어근 ‘발’이 결합했기 때문이다.
20②‘새-’는 ‘매우 짙고 선명하게’의 뜻을 더하는 접두사.
접사의 종류와 기능
21④‘-꾸러기’는 어근 뒤에 붙는 접미사. 나머지는 접두사(맨-, 들-, 시-, 헛-).
22③믿다(동사) → 믿음(명사). 나머지는 뜻만 더하고 품사는 그대로.
23(1) -개 (2) 동사 → 명사‘-개’는 ‘그런 행위를 하는 도구’라는 뜻을 더하며 명사를 만든다.
24②접두사는 품사를 바꾸지 않는다. 품사를 바꾸는 일은 주로 접미사가 한다.
새말과 다듬은 말
25⑤‘풋노인’은 접사 ‘풋-’ + 어근 ‘노인’이므로 어근 + 접사.
26③‘짬’뽕 + ‘짜’장‘면’. 돌직구·꿀잠은 어근 + 어근, 사랑꾼·풋사랑은 어근 + 접사.
27(1) 풋- + 노인
(2) 미숙한, 서투른		‘풋감’의 ‘덜 익은’이 사람에게 쓰여 ‘미숙한, 깊지 않은’의 뜻이 된다.
28①단어는 사회 변화에 따라 생기고, 바뀌고, 사라지기도 한다. 대중 매체에서도 많이 쓰인다.
29⑤‘에어캡’은 ‘뽁뽁이’. ‘1인 가구 경제’는 ‘솔로 이코노미’를 다듬은 말.
30㉡ (예시)뜻은 통하지만 입에 잘 붙지 않아 발음하기 어색하다. ‘뽁뽁이’처럼 쉽고 말하기 편한 말이 잘 퍼진다.
