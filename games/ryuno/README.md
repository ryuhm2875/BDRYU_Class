# RYUNO 류노

한글 음운으로 하는 우노.
칠판(선생님 PC)이 심판을 맡고, 학생은 각자 태블릿·휴대폰으로 들어옵니다.
서버 비용은 들지 않습니다. (Firebase 무료 요금제)

## 폴더

```
games/ryuno/
├─ index.html                  처음 화면 · 칠판 · 학생 화면 (주소 뒤에 붙는 값으로 나뉨)
├─ css/ryuno.css
├─ js/firebase-config.js       Firebase 설정 · 잠금 모드 스위치
├─ js/net.js                   연결 · 시험 모드
├─ js/rng.js                   암호용 난수 · 카드 섞기(피셔-예이츠)
├─ js/cards.js                 카드 110장 · 자음/모음 정보 · 음운 변동 콤보
├─ js/engine.js                규칙 엔진 (칠판만 실행)
├─ js/board.js                 칠판: 대기실 · 게임판 · 결과
├─ js/player.js                학생 화면
```

## 주소

| 주소 | 쓰임 |
|---|---|
| `games/ryuno/` | 처음 화면. 칠판에서 [방 만들기] |
| `games/ryuno/?board=1` | 칠판 (지난번 방이 있으면 이어서) |
| `games/ryuno/?join=방번호` | 학생 참가 (QR로 들어오면 자동) |
| `?local=1` 을 덧붙임 | 인터넷 없이 한 브라우저의 탭끼리 시험 |
| `?tab=1` 을 덧붙임 | 탭마다 다른 사람으로 접속 (PC 한 대로 여러 명 시험할 때) |

## Firebase 설정

**지금은 따로 설정할 것이 없습니다.**
품사 경매 · 음운 부루마블과 같은 프로젝트(`appleday-quiz`)를 같은 방식으로 씁니다.
데이터 자리는 `rooms/ryuno-방번호` 입니다.

손패는 각자 화면에 자기 것만 보입니다.
다만 데이터베이스 자체를 잠그지는 않으므로,
개발자 도구로 들여다보는 것까지 막지는 못합니다.

### 나중에 손패를 완전히 잠그고 싶을 때 (선택)

1. Firebase 콘솔 → **Authentication → Sign-in method → 익명 → 사용 설정**
2. **Realtime Database → 규칙**: 기존 규칙을 백업한 뒤
   `firebase/database.rules.json` 내용으로 바꿔 게시
   (기존 게임 자리 `rooms/…` 는 지금처럼 열어 둡니다)
3. `js/firebase-config.js` 에서 `SECURE = false` 를 `true` 로 바꾸기

잠금 모드에서는 학생 화면에 [훔쳐보기] · [칠판 바꾸기] 시험 버튼이 생겨,
실제로 막히는지 기기에서 확인할 수 있습니다.

## 방 번호

헷갈리는 글자(0 O 1 I L)를 뺀 31글자 × 6자리입니다.
약 8억 8천만 가지라 짐작으로 맞히기 어렵습니다.
칠판이 6시간 넘게 신호가 없으면 그 번호는 새 방에 다시 쓰일 수 있습니다.

## 게임 규칙 (고정)

- 카드 110장: 자음 72장(색마다 18장: 빨강 9종×2, 파랑 3종×6, 노랑 3종×6, 초록 ㄴㅁㅇ×4·ㄹ×6), 색마다 건너뛰기·방향 반대·+2 각 2장, 단모음 와일드 10장, +4 4장
- 색 = 조음 방법: 빨강 파열음 · 파랑 마찰음 · 노랑 파찰음 · 초록 울림소리
- 바닥 카드와 **색 · 조음 위치 · 소리 세기 · 글자 · 특수 기호** 중 하나만 같으면 낼 수 있음
- 낼 카드가 없으면 1장 뽑기. 뽑은 카드를 낼 수 있으면 바로 내거나 넘기기
- 건너뛰기 / 방향 반대(2명이면 건너뛰기) / +2(받고 쉼) / 와일드(색 고름)
- +4: 색을 고르고, 다음 사람은 방어 문제. 맞히면 2장, 틀리거나 시간 초과면 4장. 그리고 쉼
- 쌓기 없음, +4 이의 제기 없음
- 1장 남으면 [류노!]. 2장일 때 미리 눌러도 됨. 안 누른 채 다음 사람이 움직이기 전에
  다른 사람이 [잡았다!]를 먼저 누르면 2장
- 음운 변동 콤보: 바닥 카드 위에 이어 내면 다음 사람 1장
  - 비음화: ㄱㄲㅋ→ㅇ, ㄷㅌ→ㄴ, ㅂㅍ→ㅁ
  - 유음화: ㄴ→ㄹ, ㄹ→ㄴ
- 차례마다 20초(뽑은 뒤 10초, 방어 문제 12초). 지나면 자동으로 1장 뽑고 넘어감
- 가장 먼저 다 낸 사람이 승리. 나머지는 남은 장수 순

## 시험

- 엔진: `node games/ryuno/tests/engine.test.mjs`
  규칙 52가지 확인, 무작위 자동 대전 3000판, 섞기 11만 번 고르기 검사
- 화면: `?local=1` 을 붙여 한 브라우저에서 칠판 탭 1개 + 학생 탭 여러 개

## 데이터베이스 구조 (Realtime Database)

```
rooms/ryuno-방번호/
├─ meta    { host: 칠판 기기 번호, at: 마지막 신호 시각, v }
├─ pub     칠판이 쓰고 모두가 읽는 공개 정보
│          { phase: lobby|play|end, round, cfg:{size, level},
│            tables:{ 테이블번호: { p:[사람], n:{사람:장수}, turn, dir, top, color, deck,
│                                   phase, seq, dl, drawn, uno, ready, quiz(정답 빠짐), winner, ev:[최근 사건] } },
│            paused, pop(깜짝 문제, 끝나기 전엔 정답 빠짐), stars:{사람:별} }
├─ seats/기기번호   { name, on(접속 중), at }       ← 학생이 씀
├─ hands/기기번호   { tid, round, cards:[카드 번호], drawn }   ← 칠판이 씀, 화면에는 자기 것만
└─ inbox/기기번호/요청   { t: play|draw|pass|uno|catch|answer|pop, seq, card, color, choice, at }
                                                  ← 학생이 쓰고 칠판이 읽고 지움
```

- 카드 더미 순서는 칠판 기기 안에만 있고 DB에 올라가지 않습니다.
- 판정은 칠판만 합니다. 학생 기기는 '요청'만 보내고, 칠판이 도착 순서대로 처리합니다.
  `seq`(판 번호)가 다른 요청은 버리므로 두 번 누름·늦은 요청이 판을 바꾸지 못합니다.
- 칠판 상태는 칠판 기기의 브라우저(localStorage)에도 저장되어, 새로 고침해도 이어집니다.

## 배포

GitHub Pages 그대로입니다. 저장소에 올리면 1~2분 뒤 반영됩니다.

1. 파일을 고친 뒤 `python3 games/ryuno/tools/bump-version.py` 실행
   (학생 기기에 남은 옛 파일 대신 새 파일을 받게 하는 번호)
2. 커밋하고 `main` 에 올리기

## 문제 · 카드 내용 고치기

- 방어 문제: 칠판의 [문제 관리]에서 더하기·고치기·끄기 (칠판 기기에 저장, [내보내기]로 옮기기)
  기본 문제를 바꾸려면 `data/questions.json` 을 고칩니다. `a` 는 정답 번호(0부터)
- 카드 분류·설명·콤보: `js/cards.js` 의 `CONS`(자음), `VOWELS`(단모음), `COMBOS`(음운 변동)
