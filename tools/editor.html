    찾아 바꾸기 · 모든 슬라이드

    사이트에 바로 반영하려면 열쇠가 필요해요

    GitHub 저장소에 파일을 올릴 수 있는 토큰(열쇠 문자열)을 한 번 만들어 붙여 넣으면, 그다음부터는 버튼 하나로 사이트가 바뀝니다.

    1. 토큰 만들기 화면을 엽니다. (GitHub 로그인 필요)
    2. Token name: 아무 이름 (예: 수업 편집기)
    3. Expiration: 가장 긴 기간
    4. Repository access: Only select repositories → BDRYU_Class
    5. Permissions → Repository permissions → Contents를 Read and write로
    6. 맨 아래 Generate token을 누르고 나온 github_pat_… 문자열을 복사해 아래에 붙여 넣기

    사이트 비밀번호 바꾸기

    홈·학년 목차·게임 주머니·이 편집기에 들어올 때 묻는 비밀번호입니다. 바꾸면 모든 기기에서 다시 물어봅니다.

    이 비밀번호는 지나다 들어오는 사람을 막는 커튼입니다. 수업 자료 주소를 이미 아는 사람은 그 주소로 바로 들어갈 수 있으니, 정말 숨겨야 할 것은 사이트에 두지 마세요.
